## 论文硬约束

- [ ] 白色 A4，页边距上下左右至少 2.5 厘米。
- [ ] 摘要专用页含标题、摘要、关键词，原则上不超过一页。
- [ ] 电子论文第一页是摘要专用页，不含承诺书和编号专用页。
- [ ] 不设目录。
- [ ] 正文不超过 30 页；附录页数不限。
- [ ] 电子论文为单一 PDF 或 Word 文件，建议 PDF，文件不超过 20MB。
- [ ] 论文、附录和支撑材料中不存在参赛者、学校或赛区身份信息。
- [ ] 所有公开资料均在正文标注，并列入参考文献。
- [ ] 附录列出支撑材料文件，并包含全部完整可运行源程序。

## 支撑材料硬约束

- [ ] 单一 ZIP 或 RAR 文件，不超过 20MB。
- [ ] 包含所有可运行源程序。
- [ ] 包含自主查阅且被最终模型实际使用的数据。
- [ ] 包含支撑结论所必需的较大中间结果和图表。
- [ ] 文件内容与论文、附录清单和复现清单一致。
- [ ] 不包含承诺书、编号专用页、`.git/`、缓存、临时文件或身份信息。

## AI 使用硬约束

- [ ] 正文相应位置标注 AI 生成或辅助内容。
- [ ] 参考文献列出工具名称、版本/型号、开发机构和使用日期。
- [ ] 支撑材料包含 `AI工具使用详情.pdf`。
- [ ] 详情包含工具名称和版本、使用目的和环节、关键交互、采纳及人工修改情况。
- [ ] 核心建模、分析、取舍、验证和最终责任由参赛队承担。

## 竞赛期间 GitHub 边界

2026 参赛规则明确禁止竞赛期间在 GitHub 等交流平台浏览、发布或讨论赛题相关内容。本仓库仅用于赛前校赛模拟和准备。正式国赛开始前必须：

- [ ] 冻结并备份赛前工具与通用模板；
- [ ] 停止浏览或推送任何当届赛题相关 GitHub 内容；
- [ ] 使用本地、匿名、隔离工作目录完成正式比赛；
- [ ] 按官方 AI 规定完整记录竞赛期间 AI 使用；
- [ ] 赛后是否公开须服从当届规则与学校要求。

## 内部门禁

- [ ] 官方 PDF 快照、哈希和页面来源保持一致。
- [ ] Word/LaTeX 共用同一份权威正文、图表、数据和参考文献。
- [ ] PDF 页数、页面尺寸、字体嵌入、空白页和图片 DPI 通过检查。
- [ ] Word 原生公式、结构、实际渲染页数和转换清单通过检查。
- [ ] 论文与支撑材料分别运行匿名字符串扫描。
- [ ] 最终压缩包和论文均实际测量小于 20MB。
- [ ] W2 独立质检 PASS 后不再实质修改；修改则重新验收。
