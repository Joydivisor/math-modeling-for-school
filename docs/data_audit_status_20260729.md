## 当前外部阻塞

### 国家统计局

国家数据页对当前公网 IP 返回 `403 Forbidden / reason: UrlACL`。以下 8 个长历史变量统一标记 `blocked_public_access`：

- 中国实际 GDP；
- 规模以上工业增加值；
- CPI；
- PPI；
- 社会消费品零售总额；
- 固定资产投资；
- 原油产量；
- 原油加工量。

解除方式：切换到能正常访问国家数据页的网络/IP 后，按数据字典导出原始历史文件，并记录官方指标代码、查询条件、单位、值类型、调整状态、工作表、首末期和 SHA-256。新闻稿只用于端点交叉核验。

### USD/CNY

中国货币网页面可达、无验证码，但浏览器自动化在填写和导出时连续超时。该项不是公共访问拒绝，而是 `acquisition_manual_action_required`：

1. 打开人民币汇率中间价历史页面；
2. 设置 `2010-01-01` 至 `2026-07-29`；
3. 选择 `USD/CNY`；
4. 查询并导出 Excel；
5. 将未修改文件保存到 `data/raw/fx/`；
6. 回传文件名后运行工作表、日期、缺口、维度和 SHA-256 审计。

### 霍尔木兹流量

公开官方页面不能提供题目时间窗内的海峡日/周流量序列。优先使用有许可的 IEA/Kpler/Vortexa 数据；否则只能构造并明确改名为 AIS 船舶过境代理，并单独分析测量误差。
